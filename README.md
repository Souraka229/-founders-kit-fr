## 🎯 À Propos

Construire une startup est difficile. Trouver les bons outils ne devrait pas l'être.

Ce repository est un répertoire structuré de ressources essentielles pour chaque étape de votre parcours entrepreneurial — de l'idéation à la mise à l'échelle. Que vous soyez un primo-fondateur ou un entrepreneur en série, vous trouverez des outils pour le développement produit, le marketing, la levée de fonds, la gestion d'équipe, l'infrastructure IA, et bien plus encore.

**Pourquoi une version francophone ?** L'écosystème French Tech est l'un des plus dynamiques au monde avec 20 000+ startups actives, 42 000 emplois créés, et des unicornes comme Alan, Doctolib, Ledger, Contentsquare. Cette liste intègre les ressources spécifiques à la France et à l'Afrique francophone, souvent absentes des listes anglophones.

## Outils de Coding IA ✨ Nouveau

> En 2026, ~85% des développeurs utilisent des outils de coding IA quotidiennement. Ces outils sont désormais une infrastructure essentielle pour tout fondateur qui construit.

### IDEs Dopés à l'IA
- [Cursor](https://cursor.com/) — L'IDE IA de référence (fork VS Code). Mode Agent, édition multi-fichiers, 1M+ utilisateurs. **Le choix par défaut de la plupart des fondateurs.**
- [Windsurf](https://codeium.com/windsurf) — IDE natif IA par Codeium. Agent Cascade, meilleur tier gratuit, 15$/mois.
- [GitHub Copilot](https://github.com/features/copilot) — 15M+ devs. Mode Agent avec support MCP. 10$/mois Pro = meilleur rapport qualité/prix.
- [Zed](https://zed.dev/) — Éditeur collaboratif ultra-rapide avec IA intégrée. Open-source, performance-first.

### Agents Terminal IA
- [Claude Code](https://claude.ai/code) — Agent CLI d'Anthropic. Contexte 1M tokens, parallélisme multi-agents, meilleur pour le raisonnement architectural. `npm install -g @anthropic-ai/claude-code`
- [OpenAI Codex CLI](https://github.com/openai/codex) — Agent terminal open-source d'OpenAI. Moteur de raisonnement o3.
- [Aider](https://aider.chat/) — Agent CLI natif Git. Idéal pour les refactors structurés.
- [Gemini CLI](https://ai.google.dev/) — Agent terminal Google, contexte 1M tokens, tier gratuit.

### Revue de Code & Qualité IA
- [CodeRabbit](https://coderabbit.ai/) — Bot de revue de code IA pour GitHub/GitLab. Gratuit open-source.
- [Sourcegraph Cody](https://sourcegraph.com/cody) — Intelligence de code IA sur les grandes bases de code.

## Infrastructure IA & LLMOps ✨ Nouveau

> La stack LLM complète — essentielle pour tout fondateur qui intègre des fonctionnalités IA.

### APIs LLM
- [Anthropic API](https://www.anthropic.com/api) — Modèles Claude. Meilleur pour le raisonnement, la sécurité, et le long contexte (200K tokens).
- [OpenAI API](https://platform.openai.com/) — GPT-4o, o3, Embeddings, Whisper, DALL·E. Plus grand écosystème.
- [Google Gemini API](https://ai.google.dev/) — Gemini 2.0 Flash (le plus rapide), contexte 2M tokens.
- [Groq API](https://groq.com/) — Inférence ultra-basse latence (hardware LPU). Idéal pour les apps temps réel.
- [Mistral AI](https://mistral.ai/) — Modèles open-weight **français** ! Multilingue solide, API rentable.
- [Cohere](https://cohere.com/) — LLM enterprise avec embeddings et RAG excellents.
- [Together AI](https://www.together.ai/) — Inférence serverless pour modèles open-source à grande échelle.

### Frameworks d'Orchestration
- [LangChain](https://www.langchain.com/) — Framework standard pour les pipelines LLM, RAG et agents.
- [LangGraph](https://www.langchain.com/langgraph) — Workflows multi-agents avec état.
- [LlamaIndex](https://www.llamaindex.ai/) — Framework spécialisé RAG et indexation de documents.
- [CrewAI](https://www.crewai.com/) — Orchestration multi-agents avec collaboration par rôles. 32K+ étoiles GitHub.
- [Dify](https://dify.ai/) — Builder d'apps LLM low-code. 93K+ étoiles GitHub. Interface visuelle avec RAG intégré.
- [n8n](https://n8n.io/) — Automatisation de workflow open-source avec nœuds IA. Auto-hébergeable.

### Bases de Données Vectorielles
- [Pinecone](https://www.pinecone.io/) — DB vectorielle managée. Le standard pour les apps RAG en production.
- [Weaviate](https://weaviate.io/) — Moteur de recherche vectorielle open-source. Auto-hébergeable.
- [Qdrant](https://qdrant.tech/) — DB vectorielle open-source haute performance.
- [Chroma](https://www.trychroma.com/) — DB vectorielle légère open-source pour le prototypage.
- [Supabase pgvector](https://supabase.com/docs/guides/ai) — Recherche vectorielle dans Postgres.

### Observabilité LLM & Évaluation
- [Langfuse](https://langfuse.com/) — Observabilité LLM open-source. Tracing, evals, gestion des prompts. Auto-hébergeable gratuit.
- [Weights & Biases](https://wandb.ai/) — Suivi d'expériences ML, monitoring de modèles et LLMOps.
- [Helicone](https://helicone.ai/) — Observabilité LLM en une ligne d'intégration. Trace coûts, latence, erreurs.

### Hubs de Modèles

## Vibe Coding & App Builders ✨ Nouveau

> Construire des apps full-stack depuis un prompt. Pas besoin d'ingénierie approfondie. Le chemin le plus rapide de l'idée au produit déployé.

- [Bolt.new](https://bolt.new/) — Builder d'app full-stack dans le navigateur. 1M tokens/mois gratuits. Déploiement production instantané. **Idéal pour les fondateurs solo.**
- [Lovable](https://lovable.dev/) — Construire et déployer des apps web full-stack avec l'IA. Stack React + Supabase.
- [v0 by Vercel](https://v0.dev/) — Générer des UIs React depuis des prompts. Intégration Vercel/shadcn.
- [Replit](https://replit.com/) — IDE cloud + agent IA (Replit Agent). Collaboratif, déploiement en un clic.
